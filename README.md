# Blog assets

블로그 공개 이미지 저장소. Blog Writer의 **이미지 에셋**에서 업로드·검색·폴더 이동·URL 복사를 제공합니다.

- `images/`: 폴더별 이미지. 파일명에는 고유 ID를 붙여 기존 URL을 덮어쓰지 않습니다.
- `trash/`: 제거한 이미지. 에셋 목록에는 표시하지 않습니다. 파일 이동 시 기존 게시물의 이미지 URL이 끊어집니다. Git 이력과 공개 저장소에는 남으므로 비공개 삭제 기능이 아닙니다.
- GitHub Pages: main 브랜치 루트. 게시 후 배포까지 잠시 걸릴 수 있습니다.

이미지를 올린 뒤 Blog Writer에서 GitHub 게시 상태를 확인하세요. 게시 실패 시 로컬 파일은 보존되며 다시 게시할 수 있습니다.
